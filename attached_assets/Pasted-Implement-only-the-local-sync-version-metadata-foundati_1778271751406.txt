Context:
Stage 2B design identified a need for local lastSyncedVersion metadata:

* key: pipass_sync_last_version
* used later to avoid unnecessary remote merge work
* should be updated after successful upload or successful empty-vault restore
* should not affect local unlock or vault access

Add safe local sync-version storage and wire it only to already-successful sync/restore paths.
