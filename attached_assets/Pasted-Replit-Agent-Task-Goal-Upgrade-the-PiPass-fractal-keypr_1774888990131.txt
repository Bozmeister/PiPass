Implementation plan
Step 1 — Add animation loop

Locate Mandelbrot renderer used by:

FractalFullscreenViewer
KeyprintViewer
mandelbrot.ts

Add a perpetual animation loop driven by requestAnimationFrame.

Create a tiny evolving time value:

let t = 0;
function animate(now){
  t += 0.003; // extremely slow motion
  renderFractal(t);
  requestAnimationFrame(animate);
}
requestAnimationFrame(animate);

The fractal must continuously re-render using t.

Step 2 — Add gentle fractal drift (micro-zoom)

Inside mandelbrot renderer:

Use the seed to derive deterministic motion parameters:

const speed = 0.00015 + (seed % 1000) * 0.00000005;
const zoom = baseZoom * (1 + Math.sin(t * speed) * 0.015);
const offsetX = Math.cos(t * speed * 0.6) * 0.003;
const offsetY = Math.sin(t * speed * 0.8) * 0.003;

Apply zoom + offsets when mapping pixels → complex plane.

This creates slow breathing / drifting motion.

Step 3 — Animated perimeter hue rotation

We want the edge pixels to feel like they are orbiting.

When colouring pixels near the escape boundary:

const hueShift = (t * 10 + seed % 360) % 360;
const hue = baseHue + hueShift;

Use HSL colouring for edge pixels only.

Interior stays dark.

This produces the “moving pixels around the perimeter” effect.

Step 4 — Add particle halo (the magic dust)

Create a lightweight particle system rendered on top of the fractal canvas.

Requirements:
• 40–80 particles max
• orbit the circle edge
• ultra-low opacity
• additive blending

Particle init (seeded RNG):

particles = Array.from({length: 60}, (_,i)=>({
  angle: seededRandom(i) * Math.PI * 2,
  radius: 0.92 + seededRandom(i+99) * 0.05,
  speed: 0.0004 + seededRandom(i+199) * 0.0004
}));

Animate each frame:

p.angle += p.speed;
x = centerX + cos(p.angle) * radius * canvasRadius;
y = centerY + sin(p.angle) * radius * canvasRadius;

Render as tiny blurred dots.

This recreates the “pixel dance”.

Step 5 — Add soft glow / bloom

After fractal render, overlay glow layers.

Layer 1: radial gradient glow

const gradient = ctx.createRadialGradient(cx,cy,r*0.6,cx,cy,r);
gradient.addColorStop(0,"rgba(0,255,170,0)");
gradient.addColorStop(1,"rgba(0,255,170,0.08)");
ctx.fillStyle = gradient;
ctx.fillRect(0,0,width,height);

Layer 2: subtle blur bloom

ctx.globalCompositeOperation = "lighter";
ctx.filter = "blur(8px)";
ctx.drawImage(canvas,0,0);
ctx.filter = "none";
ctx.globalCompositeOperation = "source-over";

Glow must be barely noticeable.

Step 6 — Respect performance

Add auto quality scaling:

If FPS < 45 for 2 seconds:
• reduce particle count by 25%
• render fractal every 2nd frame

If FPS < 30:
• pause zoom drift
• keep only hue rotation

This ensures smooth mobile performance.

Step 7 — Deterministic seeded randomness

Create a tiny seeded RNG used by ALL animation randomness:

function seededRandom(n){
  const x = Math.sin(seed + n) * 10000;
  return x - Math.floor(x);
}

Every vault gets a unique motion signature.
